Is your repo ready for Nov 2?

From November 2, 2026, GitHub blocks pull_request_target on public repositories unless an Actions policy allows it, and since July 20 actions/checkout refuses to check out fork pull requests in those workflows. Paste a public repository to see which of its workflows are affected and what to do.

Runs in your browser

This page reads the repository's workflow files from GitHub and analyses them on your device. There's no server of ours in between and nothing is stored.

Same rules as the CLI

Identical to prt-check , and tested against the Python CLI on 9,328 workflows from the 1,000 most-starred repositories: same findings, same lines.

What it can't see

It reads workflow files only. It can't see your repository's Actions policies, and it can't tell whether a flagged workflow is still needed. Every finding points to a line to review.
